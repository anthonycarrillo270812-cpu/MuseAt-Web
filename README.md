# MuseAt-Web

MuseAt es un proyecto web relacionado con la música, diseñado para explorar canciones, descubrir géneros musicales y organizar una biblioteca musical personal. La página combina una estética grunge con una UI fácil e intuitiva.

## Características principales

1. **Explorar canciones:** visualizar las canciones organizadas en tarjetas.
2. **Buscador:** buscar canciones por título, artista o género.
3. **Reproductor de audio:** escuchar los archivos de audio disponibles.
4. **Biblioteca personal:** consultar y organizar tus canciones subidas.
5. **Subida de canciones:** añadir archivos de audio (incluyendo subir portadas).
6. **Perfil de usuario:** editar y guardar la información del usuario.
7. **Tema claro y oscuro:** cambiar la apariencia de la UI.
8. **Diseño adaptable:** adaptación de la interfaz a distintos tamaños de pantalla.

## Tecnologías utilizadas

- **HTML5:** estructura y organización del contenido.
- **CSS:** diseño visual, colores, tipografías y adaptación a diferentes pantallas.
- **JS:** funcionalidades interactivas, búsqueda, filtros, reproductor y gestión de canciones.
- **Google Fonts:** tipografías personalizadas.
- **IndexedDB:** almacenamiento local de las canciones y sus archivos.
